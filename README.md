# Site Scan 3D

Interactive 3D viewer of the 10/28/2026 Polycam scan (existing ground and fuel station).

Open `index.html`, or view it on GitHub Pages.

- Photo or elevation + 1 ft contour display
- Click the ground to read elevation; measure horizontal distance, ΔZ and slope
- Top of fuel island = 100.00 ft (assumed relative datum), US survey feet
- Local coordinates, north unknown. Phone scan, **not survey grade**.
